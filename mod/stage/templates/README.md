# (Obsolète) Gabarit de convention de stage

Ce dossier n'est plus utilisé. Les gabarits de convention (pages 2 à 4, articles juridiques)
sont désormais gérés depuis l'interface DEVE (**Gabarits de convention**, `convention_templates.php`),
qui permet d'en uploader plusieurs et de les stocker via l'API fichiers de Moodle — l'étudiant
choisit ensuite l'un d'eux au moment de sa demande de convention (`convention_request.php`).

Les deux logos affichés en haut de la page 1 (identiques pour tous les stages) se gèrent sur la
même page.
